
# Python Digital Clock

A simple digital clock application developed using Python and Tkinter. It displays the current time and date in a graphical window and updates the display automatically every second.

## Features

- Displays the current time in hours, minutes, and seconds.
- Shows AM/PM alongside the time.
- Displays the current date.
- Updates automatically every second.
- Uses a black background with white text.
- Provides a simple graphical user interface (GUI).

## Technologies Used

- **Python** — Programming language
- **Tkinter** — GUI library
- **time.strftime()** — Formats the current time and date

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)

No additional packages are required.

## How to Run

1. Install Python 3 if it is not already installed.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   ```bash
   python digital_clock.py
   ```

   On Windows, you can also use:

   ```bash
   py digital_clock.py
   ```

## Python Concepts Used

- Importing modules
- Functions
- Tkinter windows and labels
- `strftime()` for formatting time and date
- `config()` for updating label text
- `after()` for scheduling automatic updates
- `mainloop()` for keeping the GUI running
